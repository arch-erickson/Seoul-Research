# MAIN engine — internal module interfaces (v2: pure HTML)

Everything here is owned by the MAIN session. **Read the HARD CONSTRAINT box at the top of `ARCHITECTURE.md` first**: the deck must run
from the live https link or from ONE double-clicked file, with no servers, launchers, flags or installs.

Source is ES modules under `src/`; `scripts/build.mjs` bundles `src/engine/main.js` with esbuild into ONE classic IIFE script
(global `window.SeoulDeck`) and writes it **inline** into the HTML. JSON (`spec/slides.json`, `spec/timing.json`, `spec/images.json`
if present, and later `spec/copy-v2.json` / `spec/notes-v2.json`) is imported and inlined. No `fetch`, no XHR, no workers, no ES modules
at runtime, no separate font files.

## Build outputs (`dist/`)
| File | Contents |
|---|---|
| `index.html` | Web version for GitHub Pages: inline CSS (Montserrat woff2 as base64 `@font-face`), inline JS bundle, images referenced as `assets/img/*.jpg`. |
| `assets/img/*.jpg` | Copied from `assets/img/` (owned by the IMAGES session) when present. |
| `Seoul-Presentation.html` | Offline version: same page, but images inlined as base64 data URIs, resized to ≤1920 px long edge, JPEG q≈80. This one file is the whole presentation (expect roughly 10–20 MB). |
Writes are atomic (temp file, then rename). These two HTML files are the only pages: one page, three views (`?view=`).

## Views (URL param `view`, read by `main.js`)
| View | How it opens | What it shows |
|---|---|---|
| audience (default) | the file / link itself | the 1920×1080 stage, letterboxed; state leader |
| `?view=presenter` | `window.open(<same file>?view=presenter)` from a key press (P / Shift+P) or the start screen | live current slide, next preview, notes, timers, controls; follower |
| `?view=print` | for the PDF | every slide fully built, one per page (`@page { size: 1920px 1080px; margin: 0 }`), no animation, no timer overlay, diagrams `renderOnce()` then converted to `<img>`, photo slides included, appendix last |

Other params (audience): `slide=<n|key>`, `beat=<k|last>` (0-based), `static=1` (no animation, no timer, no presenter link; the on-slide
timer stays hidden unless `timer=1`), `audit=1|all` (+ `auditSlides=`, `overlay=1`), `simulateScreens=2` (+ `simulateWM=0`).
Presenter demo params (no slides window needed): `slide`, `beat`, `slideSec`, `globalSec`, `paused=back`, `auto=0`, `black=1`, `furthest=<key>`.

## Start screen (presenter view, before the timer starts)
A short checklist the speaker sees before beginning: projector connected and in **Extend** mode (Win+P), press P to present,
clicker works, and **"Submit the PDF of the presentation (the assignment requires it)"** — the user asked to be reminded before presenting.
The checklist disappears when the talk starts (first forward press).

## Engine core notes (engine-core session)
- `scripts/build.mjs [--entry f] [--copy] [--no-single] [--images-manifest f] [--out dir] [--quiet]`; the last two are for tests only.
  Prints `fallback: <id> (<reason>)` for every diagram id without a usable module. Writes are atomic; any other `*.html`, `*.js`, `*.css`,
  `*.map` and `assets/fonts/` left in `dist/` by an older build are deleted.
- Single-file images: `<script type="application/json" id="seoul-images">{ "assets/img/x.jpg": "data:image/jpeg;base64,..." }</script>`;
  `images.js resolveImage(file)` prefers that map, else the relative path (dist/index.html). Resized with sharp from
  `.tmp/main/tools/node_modules` (<= 1920 px, q80, cached in the OS temp dir); without sharp the original bytes are inlined.
- `slides.js` extras: `normalizeCopy(copy)` (copy-v2 format: array of `{ key, elements:[{ id, action, new }] }`, `{ slides }` or
  `{ [key]: [...] }`), `undash()`, `imageCredits(images)`, `APPENDIX_TITLE = 'References and Image Credits'`, `fitAppendix()`
  (largest font 17 to 10.5 px that fits 3 columns). Photos of the next two slides are pre-decoded on every `show()`.
- `print.js`: sets `<html data-print-ready="1">` and `window.__seoulPrintReady` when done (title stays the deck title = PDF title);
  diagram snapshots at pixelRatio 2. PDF: `chrome --headless=new ... --print-to-pdf=out.pdf --virtual-time-budget=15000 "<file url>?view=print"`
  gives 39 pages of 1440 x 810 pt (1920 x 1080 px).
